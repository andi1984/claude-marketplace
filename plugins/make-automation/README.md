# Make.com Automation Skill

Expert guidance for building Make.com scenarios using the Make MCP tools.

## Triggers

Auto-activates when you mention: `make`, `make.com`, `scenario`, `blueprint`, `webhook`, `integromat`

## What It Covers

- Blueprint JSON structure and validation
- Make MCP tool usage (`scenarios_*`, `hooks_*`, `data-stores_*`, `executions_*`)
- Common automation patterns (webhook trigger, scheduled sync, error routing)
- Data store patterns for caching and deduplication
- Module configuration with Make's expression syntax
- Operation cost optimization

## Requirements

Make MCP server must be connected. Check with `connections_list` if scenarios aren't loading.
