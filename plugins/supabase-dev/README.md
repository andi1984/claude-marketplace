# Supabase Development Skill

Best practices for Supabase development with MCP tool integration.

## Triggers

Auto-activates when you mention: `supabase`, `rls`, `edge function`, `supabase migration`

## What It Covers

- RLS policy patterns (user-owned, public, service role)
- Migration workflow using `apply_migration` (not raw SQL)
- Edge functions with Deno and proper auth handling
- TypeScript type generation and usage
- Auth patterns (`getUser` vs `getSession`)
- Storage with bucket policies
- Common mistakes to avoid

## Requirements

Supabase MCP server must be connected and a project must be active.
