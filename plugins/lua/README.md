# Lua Development

Lua development guidelines covering tables, metatables, error handling, game development (Love2D), and performance optimization.

## Triggers

This skill activates when working with:
- `lua` - Lua code and projects
- `love2d` - Love2D game framework

## What It Covers

- **Language Fundamentals** - Scoping, locals, idiomatic patterns
- **Tables** - Usage as arrays, dictionaries, and objects
- **Metatables & OOP** - Prototype-based inheritance patterns
- **Error Handling** - pcall/xpcall, error patterns
- **Modules** - Module pattern and best practices
- **Performance** - Optimization techniques for Lua and LuaJIT
- **Love2D** - Game development with the Love2D framework
- **Code Style** - Naming conventions and formatting
