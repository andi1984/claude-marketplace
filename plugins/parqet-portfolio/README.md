# Parqet Portfolio Commands

Quick portfolio analysis slash commands using the Parqet MCP.

## Commands

### `/portfolio`
Quick overview: current value, total return, XIRR, top holdings across all portfolios.

### `/portfolio-performance [period]`
Detailed performance breakdown. Period: `ytd` (default), `1y`, `3y`, `5y`, `max`.

```
/portfolio-performance 1y
/portfolio-performance max
```

## Requirements

Parqet MCP must be connected. Portfolio data must be set up in Parqet app.
